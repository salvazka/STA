═══════════════════════════════════════════════════════════════
   PANDUAN INSTALASI SERBA TESTER APP DI XAMPP
═══════════════════════════════════════════════════════════════

📋 LANGKAH-LANGKAH INSTALASI:

1. INSTALL XAMPP
   ────────────────────────────────────────────────────────────
   • Download XAMPP dari: https://www.apachefriends.org/
   • Install XAMPP (disarankan di C:\xampp\)
   • Pastikan Apache dan PHP terinstall dengan baik


2. COPY FILE KE XAMPP
   ────────────────────────────────────────────────────────────
   • Buka folder: C:\xampp\htdocs\
   • Buat folder baru: serba-tester
   • Copy semua file ke folder tersebut:
     ✓ index.html
     ✓ styles.css
     ✓ script.js
     ✓ system_info.js
     ✓ logo.svg
     ✓ speedtest.php


3. JALANKAN XAMPP
   ────────────────────────────────────────────────────────────
   • Buka XAMPP Control Panel
   • Klik "Start" pada Apache
   • Pastikan status Apache berubah menjadi "Running" (hijau)


4. AKSES WEBSITE
   ────────────────────────────────────────────────────────────
   • Buka browser (Chrome, Firefox, Edge)
   • Ketik di address bar:
     http://localhost/serba-tester/
   • Atau:
     http://127.0.0.1/serba-tester/


5. VERIFIKASI PHP BACKEND
   ────────────────────────────────────────────────────────────
   • Buka: http://localhost/serba-tester/speedtest.php?action=ping
   • Seharusnya muncul JSON response:
     {
       "timestamp": 1234567890.123,
       "status": "pong",
       "server_time": "2024-01-01 12:00:00"
     }


═══════════════════════════════════════════════════════════════
   TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ Apache Tidak Bisa Start
   → Cek apakah port 80 sudah digunakan
   → Buka XAMPP Control Panel → Config → Apache → httpd.conf
   → Ubah "Listen 80" menjadi "Listen 8080"
   → Akses: http://localhost:8080/serba-tester/

❌ PHP Backend Tidak Berfungsi
   → Pastikan Apache sudah running
   → Cek: http://localhost/serba-tester/speedtest.php?action=ping
   → Pastikan file speedtest.php ada di folder yang benar
   → Cek error log di XAMPP Control Panel

❌ Speed Test Gagal
   → Buka Console Browser (F12 → Console)
   → Cek apakah ada error CORS atau network
   → Pastikan PHP backend bisa diakses
   → Jika semua gagal, aplikasi akan menggunakan simulasi realistis

❌ Audio Tidak Berfungsi
   → Pastikan browser mendukung Web Audio API
   → Cek permission audio di browser settings
   → Beberapa browser memerlukan klik user sebelum audio bisa dimainkan

═══════════════════════════════════════════════════════════════
   FITUR YANG TERSEDIA
═══════════════════════════════════════════════════════════════

✅ Tes Keyboard
   → Layout penuh 104 tombol termasuk numpad
   → Meter cakupan dalam persen
   → Readout kode tombol terakhir + tombol reset

✅ Tes Kecepatan Internet
   → Ping/latency test (6 sampel + jitter)
   → Download speed test
   → Upload speed test
   → Gauge SVG + stepper fase

✅ Tes Monitor
   → 12 pola visual lengkap
   → Deteksi dead/stuck pixel
   → Gradien, banding, dan uniformity
   → Mode layar penuh

✅ Tes Audio
   → Kontrol volume (0-100%)
   → Kontrol frekuensi (200-2000 Hz) + preset
   → Pilihan bentuk gelombang (sine/square/triangle/saw)
   → Visualizer gelombang real-time
   → Tes kanal kiri / kanan / stereo

✅ System Info
   → Informasi browser & engine
   → Layar + estimasi refresh rate
   → Hardware & GPU renderer
   → Dukungan Web API
   → Export / copy JSON


═══════════════════════════════════════════════════════════════
   PINTASAN KEYBOARD
═══════════════════════════════════════════════════════════════

   Alt + 1 … 5    Pindah antar modul
   Alt + T        Ganti tema terang / gelap
   ← / → / Space  Navigasi pola pada tes monitor
   F              Layar penuh (saat tes monitor)
   Esc            Keluar dari layar penuh


═══════════════════════════════════════════════════════════════
   AKSES DARI PERANGKAT LAIN
═══════════════════════════════════════════════════════════════

1. Cari IP Address komputer Anda:
   • Buka CMD (Command Prompt)
   • Ketik: ipconfig
   • Cari "IPv4 Address" (contoh: 192.168.1.100)

2. Akses dari perangkat lain di jaringan yang sama:
   • http://192.168.1.100/serba-tester/

3. Pastikan firewall mengizinkan koneksi ke port 80
