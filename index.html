Informasi Sistem

Ringkasan browser, layar, hardware, dan dukungan Web API pada perangkat ini — berguna untuk melacak akar masalah kompatibilitas.

Hanya lokal

Kenapa ini penting

  • Web Audio API wajib aktif agar tes speaker berjalan.
  • WebGL menandakan akselerasi GPU untuk game dan konten 3D.
  • Service Worker dibutuhkan untuk fitur PWA dan mode offline.
  • Semua data dibaca di perangkat Anda dan tidak dikirim ke mana pun.
